## The Piping Pattern

### Basic Pattern
```bash
command 2>&1 | bob -p "prompt"
```

**Components:**
- `command` - Any command that produces output
- `2>&1` - Redirect stderr to stdout (capture all output)
- `|` - Pipe output to Bob
- `bob -p "prompt"` - Bob Shell with prompt
- `"prompt"` - Instructions for Bob on how to process the input

### Why This Pattern Works

1. **Captures Everything:** `2>&1` ensures both stdout and stderr are piped to Bob
2. **Non-Interactive:** Bob processes input and exits (no conversation loop)
3. **Deterministic:** Same input + prompt = consistent output
4. **Measurable:** Can track Bobcoin consumption per invocation
5. **Composable:** Can chain multiple Bob invocations

## Bobcoin Cost Analysis

### Expected Costs

| Test Type | Input Size | Prompt Complexity | Expected Cost |
|-----------|------------|-------------------|---------------|
| Basic summarization | ~500 chars | Simple | 0.1-0.2 |
| Error detection | ~100 chars | Medium | 0.1-0.2 |
| Pattern recognition | ~200 chars | Medium | 0.1-0.2 |
| Multi-stage analysis | ~500 chars | Complex | 0.2-0.4 |
| Actionable recommendations | ~100 chars | Simple | 0.1-0.2 |

### Cost Optimization Tips

1. **Keep prompts concise:** "summarize in 1 line" vs "please provide a detailed summary"
2. **Limit input size:** Pipe only relevant output, not entire logs
3. **Use specific prompts:** "list errors" vs "analyze this output"
4. **Cache results:** Don't re-run Bob on same input
5. **Batch operations:** Process multiple items in one Bob call when possible

## Integration with Auto-Recovery

### Phase 3 Usage Pattern

```bash
# 1. Run bootstrap
OUTPUT=$(./scripts/bootstrap.sh 2>&1)
EXIT_CODE=$?

# 2. If failed, ask Bob to diagnose
if [ $EXIT_CODE -ne 0 ]; then
    DIAGNOSIS=$(echo "$OUTPUT" | bob -p "identify the error and suggest recovery action")
    
    # 3. Parse Bob's response for recovery action
    RECOVERY_ACTION=$(echo "$DIAGNOSIS" | grep -oP 'Action: \K.*')
    
    # 4. Execute recovery action
    eval "$RECOVERY_ACTION"
    
    # 5. Retry bootstrap
    ./scripts/bootstrap.sh
fi
```

### Cost Management

- **Budget per auto-recovery loop:** 0.5 Bobcoins
- **Maximum retries:** 3 (total cost: 1.5 Bobcoins)
- **Fallback:** If Bobcoin budget exceeded, fall back to deterministic recovery

- No input piped to Bob
- Prompt is unclear
- Bob service temporarily unavailable

**Solution:**
