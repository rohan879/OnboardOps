## Selection Summary

### Recommended Repository
**tiangolo/full-stack-fastapi-template**

### Why This Repository?

1. **Perfect Size:** ~25-30 source files (within 10-30 target range)
2. **Comprehensive Tests:** Real test suite for both backend and frontend
3. **Maximum Drama:** 6 distinct onboarding traps for impressive auto-recovery demo
4. **Real-World Relevance:** Full-stack architecture mirrors production environments
5. **Active Maintenance:** Created by FastAPI author, actively maintained

### The 6 Identified Traps

| # | Trap | Detection Signal | Recovery Action | Demo Value |
|---|------|------------------|-----------------|------------|
| 1 | Docker not running | "Cannot connect to Docker daemon" | Start Docker, wait for ready | HIGH |
| 2 | Missing .env | Import/config errors | Copy from .env.example, populate | HIGH |
| 3 | Port conflict | "Address already in use" | Kill process or use alt port | MEDIUM |
| 4 | Database not initialized | "relation does not exist" | Run migrations, seed data | HIGH |
| 5 | Node version mismatch | Package.json engines check fails | Switch via nvm | MEDIUM |
| 6 | Service dependencies | Backend can't connect to DB | Retry with backoff | MEDIUM |
