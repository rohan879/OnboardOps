# T4.1: Bob Shell Installation and Verification Guide

**Task Owner:** Dev 4 (Infra / Bob Shell)  
**Time Budget:** 10 minutes  
**Dependencies:** None

## Overview

This task verifies that Bob Shell is properly installed, authenticated with the hackathon team, and functioning correctly. This is a prerequisite for all Bob-powered automation in OnboardOps.

## Acceptance Criteria

✅ Smoke test returns "4" (or similar minimal answer)  
✅ Bobcoin spend logged

## Manual Steps Required

### Step 1: Install Bob Shell

**For macOS:**
```bash
# Visit the official Bob Shell installation page
# https://bob.build/docs/shell (or the official IBM Bob documentation)

# Follow the installation instructions for macOS
# This typically involves:
# 1. Downloading the installer
# 2. Running the installation script
# 3. Adding Bob to your PATH
```

**Verify Installation:**
```bash
bob --version
```

### Step 2: Authenticate with IBMid

```bash
# Start the authentication process
bob --login

# This will:
# 1. Open your default browser
# 2. Prompt you to sign in with your IBMid
# 3. Ask you to select a team
```

**IMPORTANT:** When prompted to select a team, choose:
```
ibm-coding-challenge-xxx
```
(where xxx is your specific hackathon team identifier)

### Step 3: Verify Team Selection

```bash
# Check your current team
bob --team

# Expected output should contain: ibm-coding-challenge-xxx
```

### Step 4: Run Automated Verification Script

Once Bob Shell is installed and authenticated, run the verification script:

```bash
cd OnboardOps
./scripts/verify-bob-shell.sh
```

This script will:
- ✅ Verify Bob Shell is installed
- ✅ Check the version
- ✅ Confirm hackathon team selection
- ✅ Run the smoke test: `echo "what is 2+2?" | bob -p "answer in one number only"`
- ✅ Create a verification log at `notes/bob-shell-verification.log`

### Step 5: Record Bobcoin Consumption

After running the smoke test:

1. Open Bob IDE (VS Code with Bob extension)
2. Go to **Settings** (Cmd+, or Ctrl+,)
3. Search for "Bob" or navigate to Bob settings
4. Find the **Bobcoin balance** under team: `ibm-coding-challenge-xxx`
5. Record the consumption for this smoke test

**Expected Consumption:** ~0.1-0.5 Bobcoins for a simple query

## Troubleshooting

### Issue: Bob command not found

**Solution:**
```bash
# Check if Bob is in your PATH
which bob

# If not found, add to PATH (adjust path as needed)
export PATH="$PATH:/path/to/bob/installation"

# Add to your shell profile for persistence
echo 'export PATH="$PATH:/path/to/bob/installation"' >> ~/.zshrc
source ~/.zshrc
```

### Issue: Authentication fails

**Solution:**
1. Ensure you're using your IBM-provided credentials
2. Check that you have access to the hackathon team
3. Try clearing credentials and re-authenticating:
   ```bash
   bob --logout
   bob --login
   ```

### Issue: Wrong team selected

**Solution:**
```bash
# Switch teams
bob --team ibm-coding-challenge-xxx

# Or re-authenticate
bob --logout
bob --login
# Then select the correct team during authentication
```

### Issue: Smoke test returns unexpected result

**Possible causes:**
- Network connectivity issues
- Bobcoin balance depleted
- Bob service temporarily unavailable

**Solution:**
1. Check your internet connection
2. Verify Bobcoin balance in Bob IDE Settings
3. Wait a moment and retry
4. If persistent, contact hackathon support
